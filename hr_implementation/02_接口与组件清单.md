# 人力行政模块 · 接口与组件清单（实现前准备包 02）

> 统一前缀 `/api/hr`；现有接口保留不动：`/api/hr/register/*`（面试登记）、`/api/hr/job-templates`（岗位模板）、`/api/hr/parse-resumes`（AI 简历解析）、`/api/hr/export-excel`（简历跟进导出）。
> 新接口集中在后端 `hr_routes.py`（FastAPI Router，挂载到 main.py），服务层在 `utils/hr_service.py`。

## 1. API 清单

### 1.1 人员花名册 roster
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/hr/roster/list | 员工列表（分页/搜索/部门/状态/学历筛选）；敏感字段按角色自动脱敏 |
| GET | /api/hr/roster/detail/{id} | 员工详情（含合同、紧急联系人）；按角色脱敏 |
| POST | /api/hr/roster/save | 新增/更新员工（系统内维护入口） |
| POST | /api/hr/roster/delete | 逻辑删除（status=resigned）或物理删除（无关联时） |
| POST | /api/hr/roster/export | 导出 Excel（默认脱敏列） |
| GET | /api/hr/roster/reminders | 提醒中心：合同到期 30/60 天、转正当月、试用期到期、生日当月、证件有效期到期 |

### 1.2 招聘 recruit
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/hr/recruit/candidates | 候选人列表（阶段/渠道/职务筛选） |
| POST | /api/hr/recruit/candidate/save | 新增/更新候选人（含阶段变更） |
| POST | /api/hr/recruit/candidate/delete | 删除候选人 |
| GET | /api/hr/recruit/requisitions | 招聘需求台账列表 |
| POST | /api/hr/recruit/requisition/save | 新增/更新需求（部门提需求→HR 发布） |
| POST | /api/hr/recruit/requisition/close | 关闭需求 |
| GET | /api/hr/recruit/dashboard | 招聘 KPI：需求数/投递数/到面率/录用率/到岗率/平均招聘周期 + 阶段漏斗 |

### 1.3 考勤 attendance
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/hr/import/attendance | 上传考勤 Excel → 导入汇总（幂等） |
| GET | /api/hr/attendance/summary | 月度汇总（部门维度/员工维度，可选月份） |
| GET | /api/hr/attendance/template | 下载考勤导入模板 |

### 1.4 驾驶舱 dashboard
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/hr/dashboard/overview | 人员结构（部门/司龄/年龄/学历/性别）、在职数、本月入职/离职 |
| GET | /api/hr/dashboard/flow | 入职-离职趋势（近 12 月）、离职率与离职原因 Top、试用期离职占比 |
| GET | /api/hr/dashboard/reminders | 到期分布：合同到期未来 90 天、生日月历（当月生日名单） |

### 1.5 知识库 knowledge（代理现有 ecom-knowledge，锁定 hr 库）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/hr/knowledge/tree | 复用 /api/ecom-knowledge/tree（library=hr） |
| POST | /api/hr/knowledge/upload | 复用 /api/ecom-knowledge/upload（library=hr） |
| POST | /api/hr/knowledge/ask | 复用 /api/ecom-knowledge/ask（library=hr） |

### 1.6 导入引擎 import
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/hr/import/roster | 上传花名册 xlsx（指定工作表）→ 清洗/校验/幂等入库 + 报告 |
| GET | /api/hr/import/logs | 最近导入日志 |
