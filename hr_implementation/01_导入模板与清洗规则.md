# 人力行政模块 · 导入模板与清洗规则（实现前准备包 01）

> 配套：《人力行政模块_项目计划书.md》v1.1 · 数据库迁移 `database/migrations/20260825_create_hr_module_tables.sql`
> 所有导入统一走 `/api/hr/import/*` 导入引擎：解析 → 清洗 → 校验 → 幂等入库 → 生成报告（新增/更新/跳过/错误清单）。

## 1. 花名册导入（roster）— 源文件：《示例科技 员工花名册.xlsx》

**结构**：3 个工作表；**两层合并表头**（第 1 行大类、第 2 行细分字段），数据从第 3 行开始。

| 工作簿列 | 表头（第1行/第2行） | 目标字段 | 清洗规则 |
|---|---|---|---|
| A | 序号 | source_key + emp_no | `f"{sheet}:{seq}"` 做幂等键；emp_no 暂用序号 |
| B | 所属公司 | company | 默认"示例科技" |
| C | 合同类型 | contract_type | 去空白 |
| D | 部门 | dept_name | 去空白；"总经理/总经办"保留原样 |
| E | 组别 | group_name | None → ''；'/' → '' |
| F | 姓名 | name | 必填；去空白；缺失行跳过并记错误 |
| G | 岗位 | position | 去空白 |
| H | 入职日期 | hire_date | **日期清洗**：datetime→date；"2017/7/1"→date；无法解析→NULL + 记警告 |
| I | 转正日期 | regular_date | 同上 |
| J | 工龄 | seniority_text | 保留原文（"10年2月13日"） |
| K | 身份证号 | id_card + id_card_hash | 去空白/去不可见字符；15 位自动升 18 位；18 位校验位校验；出生日期提取（与 M 列核对）；散列 SHA-256 存 hash |
| L | 身份证有效期 | id_card_expiry | 日期清洗；'长期' → NULL |
| M | 出生日期 | birthday | 若为空用身份证提取 |
| N | 生日月份 | （不落库，由 birthday 派生） | — |
| O | 性别 | gender | 若为空用身份证第 17 位推断 |
| P | 年龄 | （不落库，由 birthday 派生） | — |
| Q | 民族 | nationality | — |
| R | 婚姻状态 | marital_status | — |
| S | 政治面貌 | political_status | — |
| T | 电话 | phone | 转字符串，去空格 |
| U | 邮箱 | email | 小写化 |
| V | 学历 | education | None → ''（列表统计时按"未填写"归组） |
| W | 是否统招 | is_fulltime | — |
| X | 学校 | school | — |
| Y | 专业 | major | — |
| Z | 证书编号 | cert_no | — |
| AA | 毕业时间 | grad_date | 日期清洗 |
| AB | 技术职称 | tech_title | — |
| AC | 户口性质 | hukou_type | — |
| AD | 籍贯 | native_place | 只取前一级行政区（"广东省广州市…"→"广东省"）便于统计 |
| AE | 户口所在地址 | hukou_address | 脱敏字段 |
| AF | 身份证住址 | id_address | 脱敏字段 |
| AG | 现住地址 | current_address | 脱敏字段 |
| AH | 银行卡号 | bank_card | 敏感字段（仅 admin/hr） |
| AI | 开户行 | bank_name | — |
| AJ | 是否购买社保 | has_social_insurance | 去空白 |
| AK | 是否购买公积金 | has_housing_fund | — |
| AL | 公积金比例 | fund_ratio | — |
| AM/AN/AO | 紧急联系人·联系人/关系/联系电话 | hr_emergency_contact（sort=1） | 三个字段全空则跳过该条 |
| AP/AQ | 签署合同期·开始/截止 | hr_contract(seq=1) | 日期清洗 |
| AR/AS | 2次续签合同期·开始/截止 | hr_contract(seq=2) | 同上 |
| AT/AU | 3次续签合同期·开始/截止 | hr_contract(seq=3) | 同上 |
| AV | 备注（差部分入职资料） | remark | — |
| 隐藏列（合并单元格缺口） | — | 统一补 None | 邻列空值不继承 |

**校验规则**：
- 幂等键 `source_key = f"{sheet}:{seq}"`，重导同文件：存在则**更新**（员工主档整行覆盖 + 子表按幂等键 upsert）。
- 姓名缺失 → 跳过该行并记错误；身份证非法（校验位错）→ 记录但**不阻断**（降级为警告并保留原值，HR 可修正）。
- 导出 Excel：默认**脱敏列**（身份证/银行卡/住址按掩码），admin/hr 可选全量导出。

## 2. 离职表导入（resign）— 工作表「离职员工」「2024年5月前离职人员」

- 字段映射同花名册 + AW 列「离职原因」→ resign_reason（保留原文，不做规则归类，看板端做关键词归类展示）。
- 幂等键 `source_key = f"{sheet}:{seq}"`；重导更新。
- 离职表不写入 hr_employee（保持在职表纯净）。

## 3. 考勤汇总导入（attendance）— 考勤机/钉钉/企微导出的 Excel

**标准模板列（可配置映射）**：姓名 / 部门 / 月份 / 实际出勤天数 / 迟到次数 / 早退次数 / 缺勤天数 / 请假天数 / 加班时长 / 异常次数 / 备注
- 通过 `月份 + 姓名` 匹配 hr_employee（匹配失败 → 跳过 + 报告"未匹配员工"）。
- 幂等：`(employee_id, month)` 唯一，重导同月覆盖更新。
- 数值列做数字清洗（含"次/天/小时"单位的文本截取）。
