# 离线查看测试报表

克隆完整仓库后，双击根目录 `index.html`，在左侧选择“店铺报表”。支持月份、渠道筛选和 CSV 导出，无需安装依赖。

测试数据由 `tools/generate_demo_data.py` 生成。界面问答根据同一份测试快照进行规则计算。

若希望将原 Vue 报表组件单独打包为 HTML，先安装 `frontend` 依赖，再执行：

```bash
node tools/export_shop_report_html.mjs --output outputs/test-report.html
```

此高级导出入口只应使用测试快照；根目录离线演示无需进行上述构建。
