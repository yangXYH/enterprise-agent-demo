# 测试店铺报表数据口径

数据来自固定公式生成的四家虚构店铺，覆盖测试年度的一月至九月，不代表实际经营。

- `revenue`：测试营业收入，单位元。
- `costG`：测试商品成本，单位元。
- `total_fees`：推广、平台、物流与仓储费用之和。
- `gross_profit`：收入减商品成本。
- `net_profit`：收入减商品成本和已录费用，未计人工与税费。
- `quantity`：测试商品件数；不是去重订单数或独立客户数。

任意期间的比例均以汇总后的金额计算。数据生成器、独立财务一致性测试及界面使用同一快照。

python tools/generate_demo_data.py
