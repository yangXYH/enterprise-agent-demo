# 演示报表核对规则

公开版仅包含生成的测试资料，不包含原公司审计数据、单据、成本价或历史纠错记录。

1. 按期间、渠道与店铺筛选原始测试明细。
2. 收入、成本与费用分别汇总；不得把已录费用重复扣除。
3. 项目净利 = 营业收入 − 商品成本 − 已录费用。
4. 净利率 = 项目净利 / 营业收入；不对各行百分比取简单平均。
5. 人工与税费不包含在演示计算中，不应将项目净利称为税后利润。
6. 月份筛选、页面汇总、模型问答的数据查询和报表导出应使用同一组测试记录。

测试数据规则和完整公式见 `tools/full_demo_fixtures.py`；一致性检查见 `tests/demo_data_test.py`。
