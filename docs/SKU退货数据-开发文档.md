# SKU 退货数据模块

完整源码保留工作簿导入、来源识别、去重、SKU 归一、品牌映射与汇总查询等功能。

## 导入原则

- 来源目录通过命令参数传入，不依赖开发机桌面路径。
- 按表头定位字段，忽略 Excel 锁文件与非数据辅助表。
- 保留销售和退货的符号，未知映射进入质量报告。
- 去重使用稳定来源和明细指纹，不能只用文件名或单据编号。
- 退货率应按同一筛选范围计算分子与分母，避免跨范围比较。
- 先预览质量报告，再在独立测试数据库中应用导入。

```bash
python tools/import_sku_return_data.py path/to/test-workbooks --dry-run --report outputs/test-preview.json
```

原始业务盘点、供应商明细、实际单据和历史统计结果未包含在公开版本中。离线入口的库存数据为独立生成的测试资料，不表示已经连接 ERP。
