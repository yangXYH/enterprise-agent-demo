# 公开演示版数据说明

本仓库面向面试和技术交流，公开文件使用虚构测试数据。

## 数据处理

- 移出员工花名册、考勤表、业务数据库、真实报表、质检 PDF、上传资料和人事 SQL 导出。
- 移出含真实金额、单据和审计基线的公司专用导入脚本及其对应测试。
- 移出旧日志、缓存、构建备份、公司 logo 和本地 `.env` 文件。
- 将保留源码中的原企业名称、人员名单、业务品牌标识替换为示例企业或测试标签。
- 将资料路径改为通用演示路径；公开文档不保留原业务金额与盘点结果。
- 示例种子数据使用测试用户标签和不可拨打的联系方式，配置模板仅包含占位符。
- 公开版本使用独立 Git 历史，不继承原项目历史提交。

## 可复现的测试资料

`tools/generate_demo_data.py` 通过固定公式生成全部离线演示资料，并同时写入 `demo/data.js` 与 `data/shop_report.json`。报表满足收入、成本、费用和项目净利之间的算术关系。

离线入口只读取随仓库分发的测试数据，不访问数据库或外部 API。问答为本地规则演示。项目更新与主题偏好保存在当前浏览器，清除浏览器站点数据即可恢复。

原 Vue + FastAPI 代码用于技术交流；真实服务运行需要独立配置数据库、账号和外部接口。不要将真实凭证或人员、经营资料加入公开仓库。
