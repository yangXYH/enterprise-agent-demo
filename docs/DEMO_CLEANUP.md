# 公开演示版数据说明

公开版运行原 Vue + FastAPI + MySQL 应用。保留业务组件、接口、查询计算、导入导出、持久化和权限，仅替换公司身份及业务资料，并添加完整演示初始化和启动工具。

- 原始人员花名册、考勤、业务数据库、真实报表、质检 PDF、上传资料、公司图片、环境配置与日志已移出公开目录。
- 包含原业务金额、单据或审计基线的专用导入脚本及对应测试已移出。
- 保留代码中的企业、人员与店铺名称使用示例企业和测试标签；公开版采用独立 Git 历史。
- `tools/full_demo_seed.py` 只连接受限名称的独立演示数据库，并校验归属标记；不读取原项目或原数据库。
- `tools/full_demo_fixtures.py` 通过公式生成员工、合同、考勤、招聘、商品、库存、采购、销售、经营、退货、客服和积分等记录，通过原服务产生预测、库存决策及聚合结果。
- 联系方式使用 TEST 标识，邮件域为 example.invalid；身份证测试串使用不存在的 000000 地区编码，银行测试串以零开头，不对应有效账户。用于保留原字段展示和脱敏效果。
- 设计图片为程序绘制图形，知识资料明确标注虚构；生成的 PDF 不是真实产品检验或认证。
- 测试账号使用原密码散列和会话机制，页面权限通过原权限配置保存；没有跳过鉴权。
- 模型和 ERP 集成保留原代码，公开仓库没有真实密钥。ERP 自动同步默认关闭。

首次启动自动生成资料，后续启动保留数据库和用户操作。Docker 使用独立数据库、上传和数据卷；本机模式使用专用演示库。生成附件位于被 Git 忽略的 data 与 uploads 路径，不会加入公开提交。

`demo/frontend` 为原 Vue 编译产物，源码/产物哈希记录在 manifest 中。原先独立简化的静态演示已移除。
